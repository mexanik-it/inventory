# Inventory

**Система инвентаризации компьютерного парка на C++.**  
Проект собирает детальные данные об аппаратной части ПК (материнская плата, CPU, RAM, диски, сетевые адаптеры, принтеры) и формирует отчёты в форматах XML, Excel (XLSX) и HTML. Поддерживает автоматическую отправку отчётов на FTP‑сервер.

## Особенности проекта

- **Кроссплатформенность:** единая кодовая база на C++ с отдельными модулями для Windows и Linux.
- **Статическая сборка (Linux):** собранный бинарный файл не требует внешних библиотек (работает на CentOS, ALT Linux и др. без установки зависимостей).
- **Гибкие форматы отчётов:**
  - `XML` — для хранения и передачи данных.
  - `XLSX` — табличное представление для анализа.
  - `HTML` — веб‑версия отчёта.
- **Автоматическая отправка:** встроенный модуль загрузки файлов на FTP‑сервер (скрипты для Windows `.cmd` и Linux `.sh`).
- **Независимость от ОС:** алгоритмы получения данных адаптированы под специфику каждой ОС (WMI для Windows, системные файлы/утилиты для Linux).
- **Версионирование:** поддержка тегов и релизов для отслеживания изменений.

## Установка и сборка

### Требования

- **Windows:** g++ (MinGW), CMake (опционально), права администратора (для некоторых запросов WMI).
- **Linux:** g++, make, curl4‑dev (для работы с FTP без сторонних библиотек).
- **Библиотеки (используются внутри проекта):** LibXL / OpenXLSX / xlnt (в зависимости от ветки сборки), ncurses (для цветного вывода в Linux).

### Сборка проекта (Makefile)

В проекте используется универсальный `Makefile`, поддерживающий следующие цели:

```bash
make all        # Сборка проекта (по умолчанию)
make rebuild    # Полная пересборка (очистка папки bin, компиляция всех файлов)
make clean      # Удаление временных файлов (.o) и исполняемого файла
```
