/*  CentOS 9 Stream installing package libstdc++-static                                           */
/*                                     ----------------                                           */
/**************************************************************************************************/

Обновите кэш пакетов:

  sudo dnf makecache

Установите пакет libstdc++-static:

  sudo dnf install libstdc++-static

Если пакет не найден, возможно, репозитории отключены или требуется включение 
дополнительных репозиториев.

В CentOS 9 пакет libstdc++-static может находиться в репозитории CRB (CentOS Stream 9 CRB). 
Чтобы его активировать, выполните: 

  sudo dnf config-manager --set-enabled crb

После этого попробуйте снова установить пакет:

  sudo dnf install libstdc++-static

Проверка установки
Убедитесь, что пакет установлен корректно:

  rpm -q libstdc++-static

Если команда вернёт имя пакета, установка прошла успешно.

Шаг 3. Проверьте переменные окружения
Убедитесь, что пути к библиотекам включены в переменные окружения:

echo $LIBRARY_PATH
echo $LD_LIBRARY_PATH

Если вывод пустой или не содержит нужных путей, добавьте их:

export LIBRARY_PATH=/usr/lib:/usr/lib64:/usr/local/lib
export LD_LIBRARY_PATH=/usr/lib:/usr/lib64:/usr/local/lib

Для постоянного применения добавьте эти строки в ~/.bashrc или ~/.profile.

Для CentOS 9 самый практичный способ сделать FTP‑клиент на C++ — взять libcurl. 
Под эту систему подход немного отличается от ALT: нужно правильно поставить пакет 
с заголовками, а дальше код почти не меняется. Я подобрала инструкцию, чтобы всё 
собралось без лишних танцев.

Шаг 1. Установка зависимостей
В CentOS 9 для разработки с libcurl нужен пакет libcurl-devel. Выполни в терминале:

sudo dnf install libcurl-devel

Без этого пакета компилятор не найдёт заголовочный файл curl/curl.h. 
Шаг 2. Сборка
Теперь скомпилируй программу. Я рекомендую явно указать стандарт C++ (например, c++17) 
и связать библиотеку:

g++ -std=c++17 ftp_upload.cpp -lcurl -o ftp_upload
