/**************************************************************************************************/
/*  CentOS 9 Stream installing package libstdc++-static                                           */
/*                                     ----------------                                           */
/**************************************************************************************************/

Обновите кэш пакетов:

  sudo dnf makecache

Установите пакет libstdc++-static:

  sudo dnf install libstdc++-static

Если пакет не найден, возможно, репозитории отключены или требуется включение 
дополнительных репозиториев.

В CentOS 9 пакет libstdc++-static может находиться в репозитории CRB (CentOS Stream 9 CRB). 
Чтобы его активировать, выполните: 

  sudo dnf config-manager --set-enabled crb

После этого попробуйте снова установить пакет:

  sudo dnf install libstdc++-static

Проверка установки
Убедитесь, что пакет установлен корректно:

  rpm -q libstdc++-static

Если команда вернёт имя пакета, установка прошла успешно.

можно поробовать и так:

  dnf install glibc-static
