## [4.1-1] - 2026-09-03

### Added
- Модуль `disk_info`: функции `getDisks()` и `formatDiskSize()` вынесены в отдельные функции для переиспользования.
- Поддержка вывода размера диска как целого числа ( коммерческие единицы, `product` ).

### Fixed
- Исправлена ошибка линковки `undefined reference to formatDiskSize` при сборке `inventory.exe` через g++.
- Обработка случая, когда WMI‑сервис недоступен: теперь возвращается пустой вектор вместо падения.

### Changed
- Упрощена логика: остался только цикл вывода и форматирование через `formatDiskSize`.
- Сборка проекта обновлена: в Makefile/CMake полная информация о жестких дисках теперь в одном файле `id_hdd.cpp`.
