## [5.2-2] - 2026-09-23
### Changed
- номер версии теперь зашивается на этапе компиляции, в зависимости от имени директории
```makefile
		BUILD_VERSION := $(notdir $(CURDIR))
		CXXFLAGS += -DBUILD_VERSION_STR="\"$(BUILD_VERSION)\""
	Так Makefile сам подставит имя папки и правильно обернёт его в кавычки для g++.
```

```cpp
		#pragma once

		#ifndef BUILD_VERSION_STR
		#error "BUILD_VERSION_STR must be defined via -D"
		#endif

		constexpr const char* kBuildVersionDir = BUILD_VERSION_STR;
```

## [4.1-2] - 2026-09-03
### Added
- Добавлено поле id_inv_number - инвентарный номер.

- Изменен формат XML файла.

  - Нет зависимости от COMPUTERNAME в окружении: GetComputerNameA берёт имя напрямую из системы — надёжнее в корпоративных сценариях.

## [4.1-1] - 2026-09-03
