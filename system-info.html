Руководство пользователя

Порядок эксплуатации комплекса Inventory для автоматизированного учёта материально-технического оснащения рабочих мест на операционных системах Windows и Linux.

Перейти к сведениям о системе

Программный комплекс предназначен для автоматизированного сбора и учёта сведений о материально‑техническом оснащении рабочего места сотрудника, включая персональные компьютеры, печатающие устройства, средства отображения информации, а также сетевые и аппаратные идентификаторы (IP‑адреса, MAC‑адреса) и инвентарные номера оборудования.

Функциональные возможности комплекса

Централизованный сбор данных

Автоматизированное получение сведений об оборудовании без использования переносных накопителей (USB‑носителей); передача данных осуществляется по каналам связи сети передачи данных.

Кроссплатформенная поддержка

Функционирование на операционных системах семейства Windows и Linux, в том числе в условиях применения средств защиты информации (SecretNet и аналогичных решений) и при наличии ограничений на использование USB‑портов.

Минимальные зависимости

Реализация на легковесном коде без привлечения сторонних библиотек и внешних зависимостей; совместимость с типовыми конфигурациями рабочих станций.

Сведения об ограничениях и совместимости

Программный комплекс Inventory разработан в соответствии с требованиями к средствам автоматизированного учёта имущества и совместим с типовыми конфигурациями рабочих станций, применяемых в корпоративной среде.

  • Не требуется установка дополнительных драйверов или компонентов ОС.
  • Работа в условиях ограничений на использование USB‑накопителей (без внешних носителей).
  • Совместимость со средствами защиты информации (в т.ч. SecretNet, Dallas Lock и аналогами) при наличии прав локального администратора.
  • Поддержка работы в изолированных сегментах сети (при условии доступности целевых сервисов для формирования отчётов).

Отчётность и выгрузки

Формирование и экспорт отчётов по результатам инвентаризации.

Доступные форматы выгрузки

CSV

Табличный формат для импорта в электронные таблицы и учетные системы. Кодировка UTF‑8, разделитель — точка с запятой.

JSON

Структурированный формат для программной обработки и интеграции с внешними системами через API.

XML

Формат с поддержкой схем данных (XSD) для обмена с государственными и корпоративными системами учёта.

Справочная информация

Краткое руководство по эксплуатации программного комплекса.

Порядок запуска

  • Windows: запустить inventory.exe от имени локального администратора.
  • Linux: выполнить sudo ./inventory в терминале.
  • Дождаться завершения сбора данных (вывод статуса в консоль).
  • Проверить сформированный отчёт в директории ./reports/.
